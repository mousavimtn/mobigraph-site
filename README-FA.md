# سایت پورتفولیوی موبی‌گراف

این بسته برای انتشار روی GitHub Pages آماده شده است.

## محتویات
- `index.html` صفحه اصلی فارسی و واکنش‌گرا
- `assets/mobigraph-logo.svg` لوگوی برداری
- `assets/favicon.svg` آیکن سایت
- `assets/salonyar-showcase.webp` تصویر معرفی سالن‌یار
- `assets/taghvim-plus.webp` تصویر تقویم پلاس
- `assets/nobatyar-reel.mp4` ویدئوی معرفی نوبت‌یار

## انتشار در GitHub Pages
1. از مخزن فعلی نسخه پشتیبان بگیرید.
2. فایل `index.html` و پوشه `assets` را در ریشه مخزن آپلود کنید.
3. فایل‌های هم‌نام را جایگزین کنید و تغییرات را Commit کنید.
4. در Settings → Pages مطمئن شوید منبع انتشار همان branch/folder فعلی است.
5. چند دقیقه بعد سایت را با دامنه خود بررسی کنید.

نیازی به تغییر DNS یا تنظیمات دامنه نیست؛ این بسته شامل تنظیم دامنه یا فایل CNAME جدید نیست تا اتصال فعلی ناخواسته تغییر نکند.
