# سایت موبی‌گراف — نسخه نهایی بازطراحی

این پوشه نسخه آماده انتشار سایت موبی‌گراف است.

## انتشار در GitHub Pages
1. ابتدا از مخزن فعلی GitHub یک نسخه پشتیبان بگیرید.
2. محتویات این پوشه را در ریشه مخزن سایت قرار دهید.
3. ساختار پوشه `.github/workflows/deploy.yml` و فایل `CNAME` را حفظ کنید.
4. تغییرات را Commit و Push کنید.
5. پس از پایان GitHub Actions، سایت را در `https://mobigraph.ir` بررسی کنید.

## نکات
- قیمت ثابت و تخفیف‌های زمان‌دار قبلی در صفحه تعرفه نمایش داده نمی‌شود؛ کاربر برای استعلام قیمت هدایت می‌شود.
- بنر اختصاصی جدید نوبتیار در بخش «نسخه اختصاصی» قرار گرفته است.
- تصویر سه گوشی فقط در بخش معرفی/نمونه نسخه‌ها باقی مانده است.
- فایل‌های تصویری موردنیاز در پوشه `assets` قرار دارند.
- پیش از انتشار، لینک‌های تماس و پیام‌رسان را با اطلاعات جاری کسب‌وکار تطبیق دهید.
